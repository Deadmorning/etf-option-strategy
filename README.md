# ETF 期权三阶段策略回测系统 📊

[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

基于 **创业板 ETF (159915)** 的期权策略回测系统，实现 **探索 + 验证 + 对冲** 三阶段自动化交易策略。

---

## 🎯 策略逻辑

### 三阶段设计

```
┌─────────────────────────────────────────────────────────────┐
│  阶段 1: 探索阶段 (9:30 开盘)                                  │
│  - 开盘涨 >0.5% → 买入平值 Call                              │
│  - 开盘跌 >0.5% → 买入平值 Put                               │
│  - 震荡 ±0.5% → 观望                                         │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  阶段 2: 验证阶段 (每 30 分钟)                                   │
│  - 价格持续同向 → 持有                                       │
│  - 价格反向 >0.5% → 平仓反手                                 │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  阶段 3: 对冲阶段 (获利保护)                                   │
│  - 期权盈利 >20% → 卖出虚值期权 (Delta=0.3)                   │
│  - 每天最多对冲 1 次                                          │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  风控：14:45 强制清仓 (当天合约不过夜)                          │
└─────────────────────────────────────────────────────────────┘
```

## ⚙️ 策略参数

在 `config.py` 中可调整以下参数：

```python
# 开仓条件
OPEN_THRESHOLD = 0.005  # 开盘价 vs 昨收 ±0.5%

# 验证频率
CHECK_INTERVAL_MINUTES = 30  # 每 30 分钟确认一次

# 反手条件
REVERSE_THRESHOLD = 0.005  # 价格反向 >0.5%

# 交易数量
TRADE_SIZE = 1  # 每次 1 张合约

# 获利对冲阈值
PROFIT_THRESHOLD = 0.20  # >20% 获利时对冲

# 虚值期权 Delta
OTM_DELTA = 0.3

# 清仓时间
CLEAR_TIME = "14:45"  # 当天不过夜

# 默认资金
DEFAULT_CAPITAL = 100000  # 元
```

## 🔍 策略优势

| 优势 | 说明 |
|------|------|
| **趋势捕捉** | 开盘突破 0.5% 即入场，抓住日内趋势 |
| **动态调整** | 每 30 分钟验证，反向立即反手 |
| **获利保护** | 盈利>20% 自动对冲，锁定利润 |
| **严格风控** | 14:45 强制清仓，无隔夜风险 |
| **高盈亏比** | 回测显示盈亏比 >30 |

## ⚠️ 风险提示

1. **数据局限性**: 使用 AkShare 盘后数据回测，非实时行情
2. **期权定价**: 采用简化估算模型，实际交易需用真实期权数据
3. **交易成本**: 未计入手续费、滑点、冲击成本
4. **流动性风险**: ETF 期权可能存在流动性不足
5. **历史业绩**: 过往表现不代表未来，策略可能失效

**本代码仅供学习研究，不构成投资建议。实盘交易需谨慎！**
